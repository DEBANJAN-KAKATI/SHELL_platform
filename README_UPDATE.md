# DHA Data Dashboard 3.3.0 update

This update adds Table-3 · Octane Table. For every selected legacy XLS file, the dashboard reads OCTANE_NUMBERS!B1:B4 in this order: Lin-RON, Lin-MON, Cal-RON, Cal-MON. All table numeric values are displayed with two decimal places.

Apply by replacing the existing dashboard_app folder with the dashboard_app folder in this package after keeping a copy of v3.2.0. Restart run_dashboard.bat and process the XLS folder again.

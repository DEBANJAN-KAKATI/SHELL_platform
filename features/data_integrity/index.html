Method and limitations

Statistics and modified Z scores are calculated independently for each Run / Condition / Reactor / Parameter group. The modified Z score uses 0.67449 times the deviation from the group median divided by median absolute deviation (MAD). A value is flagged when its absolute score exceeds the selected threshold.

The minimum valid sample count is fixed at 3. Groups with fewer than 3 valid samples or zero MAD are not scored. Duplicate selected measurements at the same timestamp are excluded from statistics. Missing and invalid values are reported, not imputed.

Conditions come directly from the selected source table's Condition column. DOE date ranges are not checked again. Blank, Unassigned, and error-valued conditions are flagged rather than inferred. Valid reactors and timestamps are still required for grouping, duplicate detection, and chronological charts. Naive timestamps share the same local clock; offset timestamps are normalized to UTC.

The RSD matrix compares two equally weighted reactor means within each condition using 100 times sample standard deviation divided by absolute pair mean. Missing reactor data or zero pair mean is undefined. Values above 2% are orange comparison warnings, separate from potential-outlier flags. Valid outlier values remain included in means and RSD.

Potential outliers are review prompts, not proof of errors. Drift, startup, stabilization, and changing catalyst performance can produce legitimate variation. This feature does not automatically identify steady state or change source records.
